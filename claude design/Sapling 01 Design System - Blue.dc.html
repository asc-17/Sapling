Sapling Design System — Blue
Blue variant · minimal · cool neutrals, one warm accent for action

Reference tokens and components for the student-facing web app. Everything here is meant to become a Razor component — no exotic layout, no one-off flourishes. Desktop-first, reflows to 390px. Both themes ship from one token set: every surface, border and text colour below is a variable, so the Blazor build swaps a single attribute on <html>, not a second stylesheet.

Light + dark, one token set 8pt spacing · 12-col desktop / 4-col mobile Figtree + Mukta (Devanagari-ready) WCAG AA body text, both themes

Data-viz ramp — radar, bars, trends
Series 1 is always the primary blue — the student's own data. The ramp then steps away from the brand hue (teal, plum, ochre) so a five-series radar stays legible. The accent amber #E39A3B never appears in a chart: it means "do something", and a data series shouldn't shout.
Colour rule that matters most: the score ring never turns red. A 38/100 renders in the same blue as an 82 — only the copy beneath it changes. Red on a student's score reads as a verdict, and this product is not a verdict.

07 · Skill chips & status badges

Claimed vs verified — the product's core distinction
Skill states
Python SQL Docker + Add skill
Solid border + check = verified. Proved by a test, a graded course, or a reviewed project.
Dashed border, muted fill = claimed. Student said so; we haven't checked. Never styled as failure.
Amber dot = in progress. Verification started, not finished.
The distinction is carried by border style + icon, not colour alone — it survives dark mode, colour-blindness, and greyscale print of a resume.
Status badges
Eligible 2 skills away Govt-subsidised Free Closes in 3 days Applied Shortlisted Eligible next year
"2 skills away" is a badge, not a lock. Gated opportunities stay visible and clickable — the badge is the invitation, and the detail page opens with the two skills and a one-tap route to close them.
No fee, ever Affordability is framed as a feature, not a discount.

Rules for the Blazor build
Dark is not an inversion. Three things change beyond the swap:
1 · Primary flips lightness. Blue-700 becomes blue-300, and its text colour flips to near-black. Deep blue on a dark canvas is unreadable.
2 · Elevation comes from surface steps, not shadow. #0F151B canvas → #172029 card → #1E2831 raised.
3 · Chart fills desaturate ~15% so the radar doesn't glow.
Default follows the OS. The toggle in the header persists per-account, not per-device — students switch between a lab desktop and a phone.
